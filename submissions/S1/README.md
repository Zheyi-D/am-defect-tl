# S1 的提交区

| 项 | 内容 |
|---|---|
| 负责 | 15 页 PPT 内容 + 讲稿 + 彩排计时 |
| 目标字数 | 每页 3–5 个要点；备注写讲稿与时间 |
| 参考素材 | 在线 PPT（链接见 `docs/START-HERE.md`）已搭好 15 页骨架；`results/figures/CATALOG.md`（放哪张图）；`reports/tables/`（放哪张表） |
| 完成标准 | 15 页内容完成 + 讲稿分段到人 + 彩排记录 ≥2 次且 ≤15:00 |

## 只允许在这个目录里建这些文件

- `S1_slide_outline.md`
- `S1_speaker_notes.md`
- `S1_rehearsal_log.md`
- `status.md`（必填：状态 / 字数 / 最后更新）

**不要改这个目录以外的任何东西。** 全局规则见 [`../README.md`](../README.md)。

## 提交方式

```bash
git add submissions/S1
git commit -m "S1: draft"
git push origin HEAD:submissions/S1
```

## 注意事项

总时长 15:00 展示 + 5:00 Q&A；8 人各 60–90 秒，分段要写清。彩排至少 2 次，每次记录实际用时。
