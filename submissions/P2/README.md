# P2 的提交区

| 项 | 内容 |
|---|---|
| 负责 | §1 Introduction + References |
| 目标字数 | Introduction 600 词；References IEEE ≥15 条 |
| 参考素材 | `README.md` §1（项目是什么）、`docs/AUTHOR_CODE.md`（论文方法）、`README.md` §7（引用信息）；起始 10 条 IEEE 引用见 `reports/WPS-REPORT-OUTLINE.md` §六 |
| 完成标准 | 600 词 + ≥15 条 IEEE 参考文献 + 正文有 in-text 引用 |

## 只允许在这个目录里建这些文件

- `P2_introduction.md`
- `P2_references.md`
- `status.md`（必填：状态 / 字数 / 最后更新）

**不要改这个目录以外的任何东西。** 全局规则见 [`../README.md`](../README.md)。

## 提交方式

```bash
git add submissions/P2
git commit -m "P2: draft"
git push origin HEAD:submissions/P2
```

## 注意事项

正文里必须出现 in-text 数字引用（如 [1]），不能只有末尾列表。官方要求 1.1 动机 / 1.2 目的 / 1.3 背景 / 1.4 工具 四个小标题都要有内容。
