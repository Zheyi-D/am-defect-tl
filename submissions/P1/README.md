# P1 的提交区

| 项 | 内容 |
|---|---|
| 负责 | Abstract + §4 Conclusion & Recommendations + 统稿 |
| 目标字数 | Abstract 200 词；Conclusion 350 词（合计 550） |
| 参考素材 | `reports/WPS-REPORT-OUTLINE.md` §三（三条必写结论）；`docs/SUBMISSION.md` §二（九部分结构与格式） |
| 完成标准 | 两段正文在在线文档里完成 + 本目录有 md 备份 + 统稿检查清单（见 status.md）走完 |

## 只允许在这个目录里建这些文件

- `P1_abstract.md`
- `P1_conclusion.md`
- `status.md`（必填：状态 / 字数 / 最后更新）

**不要改这个目录以外的任何东西。** 全局规则见 [`../README.md`](../README.md)。

## 提交方式

```bash
git add submissions/P1
git commit -m "P1: draft"
git push origin HEAD:submissions/P1
```

## 注意事项

统稿职责：等 P2–P4 写完，核对图表编号连续、字数（正文 ≤4,400 词）、页码、页边距、TNR 12、目录/图目录/表目录是否自动生成，最后导出 docx 到 `reports/submission/`。
